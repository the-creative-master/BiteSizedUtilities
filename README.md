# 🧰 BiteSizedUtilities

> **Small tools. Big utility. Zero fuss.**

BiteSizedUtilities is a collection of bite-sized web utilities built to make everyday tasks faster, cleaner, and way more fun. Open a tool, get the job done, and get back to what matters.

## ✨ What makes it special?

- **Quick and convenient** — tools are designed to be easy to find and even easier to use
- **Browser-powered** — no complicated setup for standard utilities
- **One clean collection** — a growing toolbox in one place
- **Built for everyone** — simple by default, powerful when you need it

## 🚀 Getting started

1. Clone the repository:

   ```bash
git clone https://github.com/the-creative-master/BiteSizedUtilities.git
   ```

2. Open the project directory:

   ```bash
cd BiteSizedUtilities
   ```

3. Launch the project using your preferred local web server or development workflow.

> 💡 Serving over HTTP(S) is recommended. Some browser features, such as the Clipboard API, require a secure context or localhost.

## 🧩 Utilities

Explore the repository for the available tools and runtimes. The project includes browser-based code tools, formatters, converters, generators, and more experimental utilities.
