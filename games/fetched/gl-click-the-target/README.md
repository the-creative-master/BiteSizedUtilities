# 🎯 Click the Target

🎯 Click the Target — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-click-the-target/

## 📸 Screenshot

![Click the Target](assets/images/screenshot.png)

## 🎯 About

Hit the shrinking targets as quickly as you can before they vanish for maximum points.

## 🕹️ Controls

- Hit: Click / Tap the target
- Restart: R

## ✨ Features

- Shrinking timed targets
- Combo multiplier
- Best score saved locally

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
