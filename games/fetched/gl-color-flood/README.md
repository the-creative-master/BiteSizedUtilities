# 🌊 Color Flood

🌊 Color Flood — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-color-flood/

## 📸 Screenshot

![Color Flood](assets/images/screenshot.png)

## 🎯 About

Flood the grid from the top-left, expanding your color to swallow every cell before you run out of moves.

## 🕹️ Controls

- Pick color: Click a swatch
- Restart: R

## ✨ Features

- Grid flood-fill puzzle
- Move limit challenge
- Color progress tracking

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
