# ✏️ Dots and Boxes

✏️ Dots and Boxes — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-dots-and-boxes/

## 📸 Screenshot

![Dots and Boxes](assets/images/screenshot.png)

## 🎯 About

Draw lines between dots to complete boxes, and claim more squares than your opponent.

## 🕹️ Controls

- Draw: Click two adjacent dots
- Restart: R

## ✨ Features

- Turn-based box claiming
- Play vs AI or friend
- Score and winner detection

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
