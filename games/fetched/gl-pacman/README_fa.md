# 👾 Pac-Man

👾 Pac-Man — یک بازی HTML5 مدرن و بدون وابستگی، ساخته‌شده با Canvas و جاوااسکریپت خالص.

🎮 **بازی آنلاین:** https://gamelabz.github.io/html5-game-pacman/

## 🎯 درباره بازی

نقطه‌ها را در ماز بخور، از روح‌ها فرار کن و پِلت‌های قدرت را بگیر تا اوضاع را تغییر دهی.

- توقف موقت: P
- شروع دوباره: R

## ✨ ویژگی‌ها

- حرکت در ماز با لبه‌های چرخ‌دار
- چهار روح با هوش مصنوعی ساده
- پِلت‌های قدرت و تعقیب امتیاز

## 🚀 اجرا در محیط محلی

نصبی لازم نیست. بازی را مستقیماً در مرورگر باز کن:

```bash
# روش اول: باز کردن مستقیم فایل
open index.html

# روش دوم: سرویس با یک سرور استاتیک کوچک
npx serve .
```

سپس به نشانی چاپ‌شده مراجعه کن (پیش‌فرض `http://localhost:3000`).

## 🛠️ تکنولوژی

- HTML5 `<canvas>`
- CSS3 (متغیرهای سفارشی، flexbox، گلس‌مورفیسم)
- جاوااسکریپت خالص (ES2020، بدون فریم‌ورک)
