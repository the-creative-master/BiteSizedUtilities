# Pong: One or Two Players — offline edition

Source: https://github.com/jakesgordon/javascript-pong
Revision: ca3240536e4f79ab7144388e56ed19de715b6662
License: MIT (full original text included).

Open index.html directly in a modern browser. All runtime dependencies are local or embedded; no installation or network required.

Controls: 1: single player; 2: two players; Q/A and P/L: paddles; Esc: quit.

Adaptation: Tutorial links removed. External-origin sound assets replaced by silent adapter.
All editions add a network-denying Content Security Policy and session-only storage adapter for scripts-only sandbox compatibility. Scores are not persisted. First-party adapters are MIT licensed (see ADAPTER-LICENSE.txt). Original copyright notices remain intact.

This is a modified offline redistribution, not an unmodified upstream release. Source entrypoint normalized to index.html. External scripts, fonts and tracking were removed where present.
