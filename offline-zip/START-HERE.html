From a folder  One command wakes all of it

A browser will not run this site straight off the disk, and it is not a broken download. Three separate rules get in the way: it refuses an ES module from a file: page, it refuses to start a worker from one, and it refuses to let one file: page open another. That is the kitchen, the code runtimes and all 51 games.

Serve the folder over http://localhost and every one of those rules stops applying. Pick your machine:

If you are onDo this
Windowsdouble-click start-server.bat
macOSdouble-click start-server.command
Linuxrun sh start-server.sh in this folder
Any of them, by hand
cd path/to/this/folder
python3 -m http.server 8123 --bind 127.0.0.1
then open http://localhost:8123/index.html

All three scripts need Python 3, which macOS and most Linux installs already have and Windows gets from python.org. They serve this folder to your own machine only, and they stop when you close the window.

Two honest caveats

  • Threaded WASM will run one thread deep. Shared-memory threads need cross-origin isolation headers, which python -m http.server cannot send. The site detects that and drops to a single thread, so the runtimes and Waffle AI still work — some of them just take longer.
  • A phone or tablet cannot do the serving. There is no local server on a tablet without a third-party app, so this folder is for a computer. That is a limit of the device, not of the zip.
